# Phal Monyvan Portfolio

Static portfolio site, ready to deploy on Vercel. The site is served directly from `index.html` and does not require a build step or dependencies.

## Deploy

1. Import this repository in Vercel and keep the Framework Preset set to **Other**.
2. Leave the Build Command and Install Command empty.
3. Set the Output Directory to `.` (the repository root).
4. Deploy.

You can also deploy from the project directory with the Vercel CLI:

```sh
vercel
```
